# Attend Web

Aplicação web do Attend alinhada ao ecossistema Tekforge.

## O que já vem
- Home pública com gateway
- Login
- Primeiro acesso
- Recuperação de senha
- Dashboard do professor / gestão
- Instituições
- Disciplinas
- Alunos
- Matrículas
- Chamadas e fila de confirmação

## Como usar
```bash
npm install
cp .env.example .env
npm run dev
```

## Build
```bash
npm run build
```
